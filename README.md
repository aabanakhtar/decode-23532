## WELCOME
This repository houses the control software for *Dunestrider,* our 2025-2026 Robot. It competed at North Carolina States and the World Championship.
![image](https://media.discordapp.net/attachments/1444873204530286672/1496701836256739458/IMG_20260422_193141439_HDR3.jpg?ex=6a009875&is=69ff46f5&hm=be2af13dc3cf057fae2a32b6f801f30d8f990415490de85438ece3e5598f1632&=&format=webp&width=966&height=904)

This code contains a somewhat robust implementation of:
- Empirically tuned shooting
- Shooting while moving
- Target locked aiming using localization
- Relocalization using Apriltags
- Command Based Programming

and more...
