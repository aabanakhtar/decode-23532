## WELCOME
This repository houses the control software for *Dunestrider,* our 2025-2026 Robot. It competed at North Carolina States and the World Championship, in Houston, TX.
[![Robot Demo](https://img.youtube.com/vi/EYRWKcV-NWo/maxresdefault.jpg)](https://www.youtube.com/watch?v=EYRWKcV-NWo)

This code contains a somewhat robust implementation of:
- Empirically tuned shooting
- Shooting while moving
- Target locked aiming using localization
- Relocalization using Apriltags
- Command Based Programming

and more...
